# 3DGS 场景加载与缓存

面向 3DGS 交互式渲染的本科毕设原型。它将预训练场景按空间分块，在有限的块缓存预算内按需上传，并根据相机近期运动预取未来可能用到的块。渲染先提交，预取上传在另一条 CUDA 流上执行，以便与当前帧渲染重叠。

## 主要结果

在 Playroom 连续轨迹的三档缓存预算下，短期预取相对 LRU 将 p99 帧时间降低 2.19–3.26 ms，总上传量增加 0.32%–4.85%。视点跳转较多时，短期预取相对固定方向预取减少 26.24% 的上传量，相对 LRU 的慢帧改善仍有不确定性。 [完整结果与适用边界](docs/experiments.md)
