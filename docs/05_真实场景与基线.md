# 真实预训练场景与全量渲染基线

2026-11-10，在 RTX 4060 Laptop GPU 上完成首个真实场景的全量常驻基线。

## 场景筛选

数据来自 Graphdeco 发布的预训练模型合集。通过 ZIP 中央目录核实了 13 个场景的第 30,000 次迭代 PLY 和配套相机文件。以下为其中具有代表性的候选。 [Graphdeco 官方仓库](https://github.com/graphdeco-inria/gaussian-splatting)

| 场景 | PLY 大小（MiB） | PLY 压缩传输（MiB） | 用途 |
| --- | ---: | ---: | --- |
| Train | 242.8 | 209.3 | 首个基线，清单中体积最小 |
| Bonsai | 294.4 | 248.5 | 室内场景候选，可用于检查跨场景适用性 |
| Truck | 601.0 | 525.0 | 较大室外场景候选 |
| Garden | 1380.0 | 1231.0 | 大场景压力测试候选 |

Train 来自 Tanks and Temples 实拍采集。已通过 HTTP Range 提取官方 ZIP 中的两个成员，实际读取约 209.3 MiB。两份文件均通过 ZIP CRC32 校验，本地 SHA256 和原始成员名记录在数据目录的 `source.json`，也随基线报告保存。 [Tanks and Temples 数据集](https://www.tanksandtemples.org/download/) · [3DGS 论文项目页](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)

## 测试口径

从 PLY 载入全部 1,026,508 个高斯，使用 float32、3 阶球谐颜色和黑色背景。将所有模型张量一次上传至 GPU 并保留。gsplat 采用 classic、packed，`radius_clip=0`。后续加载策略沿用相同渲染设置。 [Graphdeco 模型字段与激活](https://github.com/graphdeco-inria/gaussian-splatting/blob/main/scene/gaussian_model.py) · [gsplat 光栅化参数](https://docs.gsplat.studio/main/apis/rasterization.html)

将 301 个原始相机按图像名的数字顺序回放。把导出的 camera-to-world 位姿转换为 world-to-camera，按目标宽、高分别缩放焦距，主点居中。固定分辨率为 1280×720。预热 60 帧，随后在同一个进程内完整回放 3 遍。 [Graphdeco 相机导出](https://github.com/graphdeco-inria/gaussian-splatting/blob/main/utils/camera_utils.py)

墙钟帧时间从提交渲染到 CUDA 事件完成，包含调用和等待开销。图像拷回、编码和写文件在计时结束后执行。启动至首帧从读取 PLY 开始，包含解码、上传和首次光栅化，计时起点晚于 Python 导入和 CUDA 上下文初始化。操作系统文件缓存状态未控制。峰值 allocated 与 reserved 分别为 PyTorch 的活跃分配和分配器保留显存。

## 本机实测

| 指标 | 结果 |
| --- | ---: |
| 计时帧数 | 903 |
| 读取模型至首帧 | 1.95 s |
| PLY 与相机读取和解码 | 1094.5 ms |
| 模型上传与相机准备 | 62.1 ms |
| 首次渲染 | 793.0 ms |
| 平均墙钟帧时间 | 8.14 ms |
| p95 墙钟帧时间 | 10.53 ms |
| 最长墙钟帧时间 | 13.85 ms |
| 超过 33.3 ms 的帧 | 0 / 903 |
| 离屏渲染吞吐 | 122.9 帧/秒 |
| 场景张量载荷 | 231.0 MiB |
| 稳态峰值 allocated | 539.4 MiB |
| 稳态峰值 reserved | 1046.0 MiB |

已确认三遍的相机顺序和帧数一致，903 帧的时间、投影高斯计数和瓦片相交计数均为有效正值。抽查了 4 个相机视角的图像。基线是同一渲染后端下的全量参考，画质评价将使用相同相机和渲染参数进行逐帧对照。

当前设备能支撑 Train 场景的基线和下一阶段开发。这个场景的显存余量较大，缓存实验应通过实际块缓存预算制造容量压力。后续扩大场景规模或分辨率时，再依据运行峰值和是否发生 OOM 判断硬件需求。

## 复现命令

在项目目录中执行：

```powershell
python scripts/fetch_graphdeco_scene.py --scene train
.\run_python.ps1 -m scripts.render_baseline --scene data/train --output reports/baseline/train-1280x720
```

结果目录下的 `summary.json` 保存统计值和模型来源，`frames.csv` 保存逐帧结果，`trajectory.json` 保存固定相机序列及矩阵，`preview.png` 汇总 4 个抽查视角。
