## 备选：较新 Python + 源码编译

使用仍受支持的 Python 版本，重新核对匹配的 torch、gsplat tag、CUDA Toolkit 和 MSVC；Windows 说明要求编译环境。[gsplat Windows 文档](https://github.com/nerfstudio-project/gsplat/blob/main/docs/INSTALL_WIN.md)、[NVIDIA Toolkit](https://developer.nvidia.com/cuda-toolkit)、[微软 Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)。

此路线工具链可能额外占用约10–20GB，具体按安装组件核实，配置/编译预计增加1–3个集中工作日，属于估计。暂未给出未经验证的精确版本锁，不与第一批同时安装。优点是可避免 Python 3.10 环境；代价是工程工作增加。

## 第二批：预训练场景，单独审核

第一步使用脚本本地生成的高斯测试后端，不需要下载训练图像或权重。合成测试只能证明接口可运行，不能支撑最终质量和场景适用性结论。

Graphdeco 官方提供 [预训练 models.zip](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/datasets/pretrained/models.zip)，[README](https://github.com/graphdeco-inria/gaussian-splatting) 标注 **14GB**。这是完整模型合集，暂不建议整包下载；解压后及主存占用还会增加。可先探测服务器是否支持 HTTP Range 和 ZIP 目录，若支持则评估只取一个场景；现在没有验证，不承诺可以只下载其中一份。最终使用前还需查对应场景来源、数据许可与引用要求。

若找到单场景 PLY，优先核实发布者、授权、相机文件、Gaussian 属性和真实体积，而不是随意下载第三方 .pt/.pth。PLY 本身还需区分普通点云与包含 scale/rotation/opacity/SH 的高斯场景。初期目标为数十至数百MB的单场景，属于筛选目标，当前尚未锁定。

Graphdeco 官方还提供约 [60MB 的 Windows viewer](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/binaries/viewers.zip)，可选作演示/文件核验工具；不是缓存系统的必要依赖，先不下载。它不能替代可修改的渲染后端。
