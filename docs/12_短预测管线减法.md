# 短预测管线减法

四组均使用 Playroom 的 2048 块布局、同一相机轨迹、16 MiB 预取额度，以及 `render-first`、短预测与视锥交集、允许预取淘汰的 LRU 准入。唯一变量是逐块或批量上传，以及标量或向量化预测。

| 组名 | 预取上传 | 预测 |
| --- | --- | --- |
| single_scalar | 逐块 | 标量 |
| single_vector | 逐块 | 向量化 |
| batch_scalar | 批量 | 标量 |
| batch_vector | 批量 | 向量化 |

每格 16 轮 Williams 顺序，每组在四个位置各出现 4 次。热态排除首帧，组 p99 差与同帧差分别计算，并按整轮配对重采样 2000 次。主要判据为 `single_scalar − batch_vector` 的组 p99 差 95% 区间上界低于 +1 ms。连续 326 MiB 是首个验证点，通过后再测折返 298 MiB 和原始顺序 375 MiB。连续结果只用于决定是否进入压力复验。

画质检查在独立回放中逐帧与同布局 LRU 比较浮点 RGB，同时要求四组帧末常驻块顺序、需求与预取字节、淘汰字节和预测范围一致。计时回放再次核对逐帧流量。批量预取用于把 H→D 调用合并为一次，然后 clone 到独立块，因此另外报告逻辑 D→D 字节。

## 连续 326 MiB

| 管线 | 组 p99（ms） | 每遍总 H→D（MiB） | 每遍逻辑 D→D（MiB） | >33.3 ms |
| --- | ---: | ---: | ---: | ---: |
| 逐块 + 标量 | 14.73 | 245.06 | 0 | 0 / 1440 |
| 逐块 + 向量化 | 14.57 | 245.06 | 0 | 0 / 1440 |
| 批量 + 标量 | 14.65 | 245.06 | 233.33 | 0 / 1440 |
| 批量 + 向量化 | 14.64 | 245.06 | 233.33 | 0 / 1440 |

最简组合相对完整版的组 p99 差为 +0.09 ms［−0.22，+0.95］，同帧差中位数为 +0.005 ms［−0.046，+0.061］。组 p99 区间上界仅低于预定界线约 0.045 ms，连续路线通过进入压力复验的判据。

有预取的热态帧中，批量路径将 H→D 调用中位数从 8 次减为 1 次，提交中位数从约 0.93–0.96 降至 0.77 ms，CUDA 事件窗口则从约 0.90–0.92 增至 3.59–3.71 ms。向量化将预测 CPU 中位数从约 0.31 降至约 0.29–0.30 ms。逐项改变上传或预测方式的四组配对 p99 差区间均跨零。各组 RGB 审计覆盖 91 帧，最大绝对误差为零。

## 折返与跳转复验

| 轨迹与预算 | 管线 | 组 p99（ms） | 每遍总 H→D（MiB） | 每遍逻辑 D→D（MiB） | >33.3 ms |
| --- | --- | ---: | ---: | ---: | ---: |
| 折返 298 | 逐块 + 标量 | 15.94 | 538.17 | 0 | 0 / 2880 |
| 折返 298 | 逐块 + 向量化 | 15.99 | 538.17 | 0 | 0 / 2880 |
| 折返 298 | 批量 + 标量 | 16.14 | 538.17 | 466.88 | 0 / 2880 |
| 折返 298 | 批量 + 向量化 | 15.47 | 538.17 | 466.88 | 0 / 2880 |
| 原始顺序 375 | 逐块 + 标量 | 37.90 | 5965.92 | 0 | 70 / 3584 |
| 原始顺序 375 | 逐块 + 向量化 | 35.99 | 5965.92 | 0 | 60 / 3584 |
| 原始顺序 375 | 批量 + 标量 | 36.72 | 5965.92 | 264.31 | 68 / 3584 |
| 原始顺序 375 | 批量 + 向量化 | 38.19 | 5965.92 | 264.31 | 78 / 3584 |

最简版在折返的组 p99 比完整版高 0.47 ms，区间［+0.06，+0.88］ms，通过 +1 ms 界线。原始顺序的差为 −0.30 ms，区间［−2.79，+1.64］ms，超过预定上界。慢帧为 70 对 78，配对慢帧率差为 −0.22 个百分点［−0.92，+0.39］。

固定向量化时，批量相对逐块的组 p99 在折返低 0.52 ms［−0.81，−0.17］，在原始顺序高 2.21 ms［+0.08，+4.82］。原始顺序每遍有 23 个热态帧实际发起预取，批量将这些帧的 H→D 调用中位数从 36 降到 1，提交约从 3.03 降到 2.67 ms，预取尾等待中位数却从约 0.002 增至 0.115 ms。这些阶段数据对应当前回放与上传实现。

三格共 192 遍，分析 31,616 个热态帧。独立画质回放共比较 1988 帧次，三条路线四组的 RGB 最大绝对误差均为零，且逐帧缓存顺序、字节与预测范围一致。

## 管线选择

| 相对批量 + 向量化 | 连续 326 的组 p99 差（ms） | 折返 298 的组 p99 差（ms） | 原始顺序 375 的组 p99 差（ms） |
| --- | ---: | ---: | ---: |
| 逐块 + 标量 | +0.09［−0.22，+0.95］ | +0.47［+0.06，+0.88］ | −0.30［−2.79，+1.64］ |
| 逐块 + 向量化 | −0.06［−0.32，+0.07］ | +0.52［+0.17，+0.81］ | −2.21［−4.82，−0.08］ |

2×2 对照中筛出的减法候选是逐块上传加向量化预测。这个组合的三个配对区间上界均低于 +1 ms，每遍省去 233.33–466.88 MiB 的逻辑 D→D。以下独立复验用于判断能否将其作为最终管线。

## 原始顺序的独立 A/B 复验

新启动的测量进程仅比较逐块加向量化和批量加向量化。原始拍摄顺序 375 MiB，16 轮 AB／BA 交替，每种管线在两个位置各出现 8 次。32 遍共分析 7168 个热态帧。两组的逐帧需求、投影高斯数量、常驻字节、淘汰字节、预取量与预测范围一致。主要判据沿用组 p99 差的 95% 区间上界低于 +1 ms。

| 管线 | p95（ms） | 组 p99（ms） | 每遍总 H→D（MiB） | 每遍逻辑 D→D（MiB） | >33.3 ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 逐块 + 向量化 | 28.18 | 38.06 | 5965.92 | 0 | 72 / 3584 |
| 批量 + 向量化 | 27.08 | 37.20 | 5965.92 | 264.31 | 56 / 3584 |

逐块减批量的组 p99 差为 +0.86 ms［−1.24，+1.91］，超过预定区间上界。同帧差中位数为 +0.024 ms［−0.032，+0.089］，同帧差 p99 为 +5.62 ms［+5.11，+6.44］，3584 对中有 1728 对在逐块路径下更快。有 35 对只有逐块超阈，19 对只有批量超阈，配对慢帧率差为 +0.45 个百分点［+0.14，+0.75］。

两种管线每遍的无效预取均为 130.39 MiB。对有预取的热态帧，批量将上传提交中位数从 3.00 降至 2.52 ms，预取事件窗口从 2.95 增至 4.37 ms，预取尾等待中位数从约 0.001 增至 0.114 ms。这些阶段量体现当前实现的传输取舍。逐块路径省去逻辑 D→D，独立样本中组 p99 的区间仍超出容忍界线，慢帧率也更高。**论文和答辩采用 `render-first`、批量上传和向量化预测**，逐块路径作为消融中的取舍保留。完整策略矩阵和离线演示使用的也是这套配置。
